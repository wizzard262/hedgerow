Paris street plans

Rows of Paris buildings on the edges between the streets and the courtyards, working as hedges, as the ruins do at Stalingrad. Every row is one of the four looks (A Haussmann, B Haussmann block with domed corners, C old Paris, D boulevard shops). The same game (seed 11) in each plan; every game makes new streets. "Play it" opens the game on that plan.
